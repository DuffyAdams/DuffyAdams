# Hey, I'm Duffy Adams 👋

I'm a developer who builds things because I get annoyed by little problems that should already have better solutions.

Most of my projects start the same way:

I'm using an app, sitting in traffic, registering for classes, working out, or doing something repetitive, and I think:

> "Why is this harder than it needs to be?"

So I build something to fix it.

I like making software that is actually useful in real life. Not just projects that look good on a resume, but tools that solve problems I personally run into — and hopefully help other people who have the same frustrations.

---

## The kind of stuff I like to build

I like building practical tools, utilities, dashboards, browser extensions, and full-stack apps.

The common theme is that every project usually comes from a real problem I had.

Sometimes it is a small convenience thing.  
Sometimes it is a full app.  
Sometimes it starts as a random idea at midnight because I got tired of doing something the slow way.

But the goal is always the same:

**Make something useful.**

## Why I build my projects

### 🖱️ Volume / Taskbar Scroller

I built my volume/taskbar scroller because I wanted a faster way to control my computer.

I hated having to move my mouse all the way down, find the tiny volume icon, click it, wait for the slider, and then adjust the volume. It felt like such a small thing, but I do it all the time.

So I made a tool that lets me quickly scroll and adjust things faster.

It is simple, but it is one of those projects that immediately made my own setup feel better.

---

### 🚦 San Diego Traffic Watch

I built San Diego Traffic Watch because I was tired of sitting in traffic and having no idea what was going on.

Sometimes traffic is backed up for miles, and all you know is that you're stuck. You do not know if it is a crash, construction, a stalled car, police activity, or something else.

Knowing what happened might not magically make traffic move faster, but it does help you make better decisions.

Maybe you switch lanes earlier.  
Maybe you take a different route.  
Maybe you just feel less frustrated because you finally know why everything is stopped.

That is what I wanted: a real-time tool that made traffic feel less random.

---

### 🏋️ Flex

I built Flex because I love workout tracking apps, but I always felt like a lot of them were almost perfect.

They had good ideas, but there were always a few things missing or a few parts that felt more complicated than they needed to be.

I wanted a workout app that felt cleaner, faster, and more focused on how people actually lift.

Something with better routines, better progress tracking, a smoother workout flow, and fewer annoying steps between starting a workout and logging a set.

So I started building the workout app I wanted to use myself.

---

### 📚 Canvas File Grabber

I built Canvas File Grabber because downloading school files one by one was driving me crazy.

Some professors would upload a bunch of separate files, and I would have to click each file, open it, hit download, go back, and repeat that over and over.

That was time I could have spent studying, working on assignments, or doing literally anything else.

So I made a browser extension that could bulk download the files I needed from Canvas.

It was one of those projects where the problem was simple, but solving it made life way easier.

---

### ⭐ SDSU RateMyProfessors Integration

I built my SDSU RateMyProfessors integration because class registration can be stressful.

Seats fill up fast, and sometimes you only have a few seconds to decide which class or professor to pick.

There were times where I wanted to check RateMyProfessors before registering, but by the time I searched the professor, opened the page, read the rating, and came back, the class could already be full.

So I made an integration that shows professor ratings directly on the registration page.

That way, I could make a faster and more informed decision without leaving the page.
